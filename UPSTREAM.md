# Upstream attribution

Aiagentsonic contains an adaptation of [OpenManus](https://github.com/FoundationAgents/OpenManus), originally published by manna_and_poem and the OpenManus team under the MIT license.

The source was extracted from the `OpenManus/` directory of the previous private Aiagentsonic snapshot `f641ba20f35b58df95f4081d0e93a6a574b54c46`. Its original `LICENSE` and source attribution remain intact. The package metadata retains the original authorship information.

This publication starts a clean history for privacy. It is not a claim that Luay Sharqiya wrote the upstream framework. Historical commits, runtime output, old documentation, assets, local setup material, and automation workflows were intentionally excluded.
